# Agent Classification App

Приложение на FastAPI для классификации уровня девиантного риска по признакам из `dataset_deviant_50_final.xlsx`.
Интерфейс сравнивает прогноз ML-модели с качественной оценкой LLM: показывает класс модели,
вероятности по классам, вердикт LLM, уверенность LLM и краткое описание факторов.

Исходные файлы курсовой и датасета остаются на месте. Новая структура проекта:

- `scripts/train_model.py` - обучение моделей из раздела классификации и сохранение лучшей по `Macro F1`.
- `models/deviant_risk_model.joblib` - сохраненная модель после запуска обучения.
- `app/main.py` - FastAPI-приложение с HTML-формой и JSON API.
- `app/ml/` - признаки, загрузка модели и функция предсказания.
- `app/templates/index.html` - HTML-интерфейс для ввода признаков, прогноза модели и сравнения с LLM.

## Запуск

```powershell
python -m pip install -r requirements.txt
python scripts/train_model.py
python -m uvicorn app.main:app --reload
```

После запуска откройте:

```text
http://127.0.0.1:8000
```

JSON API доступен по адресу `POST /api/predict`.

## Сравнение ML и LLM

Приложение умеет отправлять входные признаки и результат ML-модели в Polza AI через OpenAI-compatible API.
LLM формирует собственный качественный вердикт по признакам, оценивает уверенность в процентах,
сравнивает этот вердикт с прогнозом ML-модели и затем описывает ключевые факторы.

В LLM-запрос не передаются метрики качества обучения, поэтому текст не должен содержать шаблонные
формулировки вроде точности Random Forest. Финальная оговорка о неокончательном заключении также
не добавляется в описание.

Создайте файл `.env` рядом с `.env.example`:

```text
POLZA_API_KEY=ваш_api_ключ
POLZA_MODEL=deepseek/deepseek-v4-flash
POLZA_BASE_URL=https://polza.ai/api/v1
LLM_MAX_OUTPUT_TOKENS=500
```

Если в личном кабинете Polza AI у DeepSeek указано другое имя модели, замените только строку модели:

```text
POLZA_MODEL=нужный_id_модели
```

Если ключ не задан, прогноз классификатора всё равно работает, а в блоке сравнения будет показано сообщение о недостающей настройке.
