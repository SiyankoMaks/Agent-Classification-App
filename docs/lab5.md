# Разработка обеспечивающих подсистем ИС

Контур `app/lab5` работает отдельно от первоначального приложения `app.main`.
Применение ограничено открытыми агрегатами и искусственными профилями. Не загружайте персональные данные и не используйте оценки для решений о людях.

## Запуск

1. Установить зависимости: `python -m pip install -r requirements.txt`.
2. Создать отдельную базу PostgreSQL 16, указать `LAB5_DATABASE_URL` в виде `postgresql+psycopg://<user>:<password>@127.0.0.1:5432/<database>`.
3. Выполнить `python -m app.lab5 init`, затем `python -m app.lab5 user demo analyst`. Вторая команда выдаёт ключ, который надо хранить отдельно от исходного кода. Команды `init` и `user` выполняет оператор с доступом к БД; они не доступны из веб-интерфейса.
4. Выполнить `python -m uvicorn app.lab5.web:app --host 127.0.0.1 --port 8000`. Открыть `http://127.0.0.1:8000/docs`, нажать **Authorize** и ввести ключ. Для сетевого использования необходим защищённый транспорт и отдельная настройка прав БД.

## Учебный сценарий

- `POST /datasets`: файлы CSV UTF-8 или XLSX с одним листом; до 10 МиБ и 10 000 строк. Общие поля формы: код и описание источника, дата обновления `YYYY-MM-DD`, `synthetic`. Ответ содержит версию или протокол с полем и строкой.
- IN01: `territory,level,year,age_band,indicator,unit,value`. Код показателя однозначно определяет единицу (проценты — `%`); пустое `value` не заменяется нулём. `POST /territory` получает версию, возрастную группу, уровень, годы, необязательные территории, цель, факторы и настройки разбиения.
- IN02: `pseudonym` и колонки `FEATURE_COLUMNS` из `app/ml/features.py`. Только искусственные профили; возраст 12–17. IN03: `pseudonym,class_code`, в форме обязателен `profile_dataset` — ID готовой версии IN02. `POST /models` создаёт версию модели по IN03, `POST /classify` оценивает сохранённый профиль этой или другой совместимой версии IN02. Передача признаков LLM отключена по умолчанию; `external:true` и настроенные переменные `POLZA_API_KEY` и `POLZA_MODEL` нужны одновременно.
- IN04: тело запроса анализа или обучения. `seed` фиксирует разбиение, `test_size` — доля контрольных строк. Территориальное сравнение иллюстративно: при повторяющихся территориях оно не измеряет качество на новых территориях или будущих годах.
- `GET /runs` — история; `GET /runs/{id}` — исходные результаты; `GET /runs/{id}/view` — HTML с графиком; `POST /runs/{id}/comments` — отдельный комментарий; `GET /runs/{id}/export/{csv|xlsx|pdf}` — выгрузки. CSV/XLSX содержат все числовые ряды; в XLSX они хранятся текстом для сохранения точного представления чисел. PDF — сводка на кириллице; при отсутствии системного шрифта задать `LAB5_PDF_FONT` (TTF).

## Копия

Создать ключ администратора командой `python -m app.lab5 user operator admin`, передать его через `LAB5_TOKEN`. Команда `python -m app.lab5 backup lab5.dump` создаёт архив PostgreSQL и файл `.sha256`. Команда `python -m app.lab5 restore lab5.dump` восстанавливает проверенный архив в отдельную пустую БД из `LAB5_RESTORE_DATABASE_URL`. Утилиты `pg_dump` и `pg_restore` должны быть в PATH или в каталоге `LAB5_PG_BIN`. Хранить архивы с ограниченным доступом; не использовать неподконтрольные архивы или модели. Архив включает версии таблиц и модели, поскольку последние хранятся в БД.
